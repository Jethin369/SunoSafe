# Product definition

## One-line pitch
SunoSafe turns a suspicious call into an evidence-led safety briefing in a language a family can understand.

## MVP user flow
1. User uploads a <=60-second synthetic or consented audio clip.
2. Backend sends it to Gnani Prisma v2.5 and receives transcript text.
3. Local rules detect potentially concerning phrases and return evidence snippets, explanations, and safe next steps.
4. UI highlights evidence in the transcript and shows a heuristic signal score.
5. User can request a spoken Hindi safety summary generated by Gnani Timbre v2.5.

## Current boundaries
- Not a definitive scam detector and not calibrated as a probability.
- No caller ID lookup, URL reputation, malware scanning, or bank/government integration.
- No app-side audio file persistence and no user accounts/database in the MVP.
- Sample mode analyzes fixed illustrative text; it must not be presented as actual model transcription.

## Quality gates before demo
- [ ] Live Prisma test with user's challenge API key.
- [ ] Live Timbre test with the configured voice and language.
- [ ] Test no key, invalid key, no-speech clip, oversized file, and unsupported extension.
- [ ] Labelled evaluation set (at least 20 synthetic scripts; report limits honestly).
- [ ] At least one benign call and one warning-signal call in the demo.
- [ ] Confirm all demo recordings are synthetic or consented and contain no actual PII.
- [ ] Check app at desktop width and narrow mobile width.
- [ ] Run `pytest -q` from a clean virtual environment.
- [ ] Public post includes #GnaniAI and #GreatIndianAIInternshipChallenge and tags the official account.
